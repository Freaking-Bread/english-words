# 📘 Мои английские слова

Персональный сайт для изучения английских слов: свои значения/ассоциации, отметка «выучил»,
кнопки на реальные клипы из фильмов (PlayPhrase/YouGlish), поиск и режим редактирования.
Работает на телефоне и ПК.

## Архитектура: публичный код + приватные данные

Статический сайт (без сборки) хостится на бесплатном **GitHub Pages** из этого публичного
репозитория. Реальные слова хранятся **не здесь**, а в отдельном приватном репозитории
`english-words-data`, чтобы личная лексика не была видна публично.

```
english-words/            ← публичный репозиторий (только код + демо-слова)
├── index.html            # разметка страницы
├── css/styles.css        # оформление, светлая/тёмная тема, адаптив
├── js/
│   ├── config.js         # настройки: указывает на приватный репо данных
│   ├── store.js          # данные: состояние + localStorage + CRUD   ← «бэк»
│   ├── github.js         # синхронизация с GitHub (pull/push)        ← «бэк»
│   └── app.js            # интерфейс: рендер, редактирование, тема    ← «фронт»
├── data/words.json       # ДЕМО-слова (публичные, безобидные)
└── .nojekyll

english-words-data/       ← приватный репозиторий (реальные слова)
├── words.json            # твоя настоящая база слов
├── WORDS.txt             # исходный список
└── import.mjs            # WORDS.txt → words.json
```

## Как это работает

1. Открываешь сайт (публичный URL GitHub Pages) — видишь демо-слова.
2. Жмёшь ☁️ → вставляешь свой GitHub Personal Access Token (с доступом к приватному
   репо `english-words-data`) → «Загрузить из GitHub».
3. Приложение подтягивает твои реальные слова. Правки, новые слова и отметки «выучил»
   коммитятся обратно в приватный репозиторий. Токен хранится только в браузере устройства.
4. На телефоне — то же самое: открыл URL, один раз вставил токен, всё синхронизировано.

## Локальный запуск

Открывать `index.html` напрямую нельзя (браузер блокирует модули с `file://`). Нужен сервер:

```bash
npx serve .
# или
python -m http.server 8000
```

Открой http://localhost:8000
